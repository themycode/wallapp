# 墙纸展示小程序

这是一个基于 **微信小程序** 的“壁纸展示与下载”应用。主要用于浏览精选壁纸、预览高清大图、并将喜欢的壁纸保存到本地。

## ✅ 核心功能

- **壁纸浏览**：在首页展示壁纸列表，支持上滑加载更多。
- **壁纸预览**：点击壁纸可在预览页查看大图并支持手势缩放。
- **壁纸下载/保存**：将壁纸保存到手机相册（需授权相册权限）。
- **基础设置 & 说明**：包含关于页面和使用说明（可在 `pages/about/` 中修改）。

## 📁 项目结构（主要目录）

- `pages/`：小程序页面目录
  - `index/`：主页面（壁纸列表）
  - `preview/`：壁纸预览页
  - `logs/`：日志页面（示例）
  - `about/`：关于页面
- `utils/`：工具脚本
  - `api.js`：接口调用或数据请求逻辑
  - `util.js`：通用工具函数
- `images/wallpapers/`：本地壁纸资源（示例图片）
- `app.js/app.json/app.wxss`：小程序全局配置和样式

## 🚀 运行说明（开发调试 + 预览）

1. 打开【微信开发者工具】，点击“+”或“打开”并选择本项目根目录（含 `app.json` 的文件夹）。
2. 进入“详情”页（通过右上角小齿轮进入）：
   - **AppID**：填写你的小程序 AppID（测试号/体验版/正式版）。若没有可选择“无 AppID”，并使用体验版预览。
   - **项目设置**：可根据需要开启/关闭 ES6 转 ES5、激活编译等选项。
3. 点击【编译】查看效果；可在“调试”面板查看日志和网络请求。
4. 若要让其他用户体验：点击【预览】生成二维码，用微信扫码即可在手机上预览。

> ⚠️ 如果在保存壁纸时出现权限提示，请在手机上允许小程序访问相册。

## 🔧 代码说明（拓展点）

- **数据来源**：可在 `utils/api.js` 中配置网络接口或本地数据源。
- **页面展示**：在 `pages/index/index.wxml` 中修改布局和样式。
- **下载权限**：保存至相册时需要用户授权，相关逻辑可在 `pages/preview/preview.js` 中找到。
